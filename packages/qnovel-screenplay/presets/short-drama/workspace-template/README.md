# 剧本项目工作区模板

每部剧一个独立目录，复制本模板后重命名为剧名（如 `废柴逆袭`）。子目录约定：

| 目录 | 存放内容 |
|------|----------|
| `创作合同/` | 立项参数表、四张表（恨账表 / 记分牌 / 情绪弧线单 / 认知仓位表）、情绪账目单 |
| `人物/` | 人物小传、反派原型语录采集（≥20 条附出处） |
| `设定/` | 世界观、信息差摆法、爽点引擎、关键数字记分牌 |
| `大纲/` | 全剧大纲（2–6 自然段，第三人称） |
| `分集大纲/` | 逐集集纲（`### 第N集` + 导语 + 正文） |
| `剧本/` | 正文（每集一个文件，守格式规范） |
| `交付/` | 情绪账目单、投流标题、交付清单 |

> 动笔前必建四张表并写入 `创作合同/`；每批剧集交付必附情绪账目单（写不出来＝走剧情，不送审，直接重写）。
