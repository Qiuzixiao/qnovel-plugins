# 短剧创作总纲

> **短剧不是故事，是债务系统**——观众用时间和充值入股，剧必须持续给他记账。走剧情的写作回答"接下来发生什么"，进度单位是事件；走情绪的写作回答"观众账户变动了什么"，进度单位是债。爽剧只承认后者。

## 核心口诀（动笔前默背）
1. **八字选题**：情绪普世 × 情节离奇
2. **情绪账务**：恨账 — 存债／付息／兑付
3. **压爽循环**：卡点 1:1，压—爽交替推进
4. **付费闸门**：在情绪欠债最狠处收账
5. **成本红线**：正文格式守第9章、字数控本守第7章

## 生成期唯一生成问题（防走剧情）
执笔时默认生成问题"接下来合理地会发生什么"，产出的必然是剧情。**强制替换为：**
> "观众的账户现在需要哪一笔？观众现在最想看谁疼？"

## 全剧每一场戏必须是三种动作之一，否则非法
- **存债（压）**：反派每欺负一次，观众账户存一笔恨。须满足——可清算账户、观众已持牌（知道底牌/法条/成本价）、加注不原地转（每次拉扯必须进新罪证/数额/受害者/底线突破，账表多一行才算数）。
- **付息（小爽）**：怼一句、噎一下、抖机灵；频率红线 30秒~1集一次，防观众绝望弃剧。付息不清账。
- **兑付（打脸）**：本金偿还。两条具名附则——①立约附则：兑付价码让观众提前知道，用具体数字（"让这一万一千九百四，变成十一万九千四"）；②续账附则：本金还清的同一集内必须开一笔新账，账户清零=观众销户（仅大结局可清账）。

一句话总纲：**压是存债，爽是付息，打脸是兑付，卡点是催收通知单，剧情只是记账用的纸。**

## 爽点账目 6 律（H级，一票否决）
1. **恨账专户律**：对主角的一切攻击只能出自"可清算账户"角色（反派）；亲人只许糊涂、不许可恨，两线分灶。
2. **反派沾亲带故律**：恨点角色优先设为与主角家庭有财产纠葛的亲戚，用「一句称呼+一句旧账」完成关系/标的/恩怨/原型。
3. **主角无视律**：对杂鱼最高回应是零回应，地位用「选择跟谁说话」表达。
4. **双频姿态律**：冷面只对反派，对受害者允许笨拙（锋利+钝感=人味）。
5. **得意报应同框律**：反派得意巅峰帧与报应第一帧同框再切。
6. **公私双刀律**：当众逼宫压面子 + 耳边低语压罪行，确立「观众+反派持牌、群众不知」信息差。

配套裁定：无视律与存债不冲突（羞辱照常入账，零回应本身是付息）；受害者可攻击主角但定性是"糊涂"不是"可恨"，债转记反派名下。

## 最高杠杆决策律（改写判断）
- **低认知负荷**：人物可复杂，表达不能混乱；答案可延迟，期待不能模糊。晦涩=观众看不见账户=弃剧。
- **尊严条款（H级不降）**：主角可以输局面、不能输尊严；禁当众社死/狼狈/哀求；不能长期失去行动权。
- **反派自毁引擎**：反派每开口、动手一次，必须给自己加一条罪或吃一次亏（当场可见）。
- **禁止主角缺席**：主角不得连续2集下线（P级）；缺席集必须写明"观众在替主角等什么账"。
- **结构病禁靠润色掩盖**：故事核/承诺/主角行动力坏，按四级修改处置，不许只改台词粉饰。

## 创作账本（不建表不许动笔）
- **恨账表**：每个反派名下存了哪几笔、哪集存的、计划哪集清算。
- **记分牌**：观众正在追的具体数字；每集自查是否被提醒或变动，三集不动=观众忘账。
- **每集情绪弧线单**：一集一行——"观众此刻的情绪是___，他在等___"。前空只准填内脏词（气/恨/急/爽/幸灾乐祸；存债段允许心疼）；后空必须填得出具体应收账款。
- **认知仓位表**：谁还以为什么、第几集爆仓、爆仓方式（反转=强平重建仓）。
- **情绪账目单（强制交付物）**：每批剧集交付必附——本批存了哪些债（逐笔）、付了哪些息、兑付了什么、开了什么新债、记分牌现值。**账目单写不出来=走剧情，不送审，直接重写。**

## 创作流程十一步（硬工序）
```
⓪ 过选题闸门（四基因逐项打分，两项空缺不立项）
→ ① 定核心燃料 → ② 定情绪承诺与故事核（过四问）
→ ③ 定高概念与爽点引擎 → ④ 定主角赢法
→ ⑤ 定反派作恶逻辑 + 原型语录采集（≥20 条附出处）
→ ⑥ 建账本与清算表 → ⑦ 建弹药库（带元数据：谁发动/为什么发动/改变什么/对应恨账哪笔）
→ ⑧ 排阶段大纲 → ⑧.5 首集方案过十检
→ ⑨ 排分集卡点与反转位点，锁付费闸门位并倒排铺垫
→ ⑩ 建四张表 → ⑪ 分批写正文（格式守第9章、成本守第7章）
→ ⑫ 验收（四表两单，不过按四级修改处置）
```

## 每集硬指标（写作/验收红线速记）
- 单集体量按立项参数执行（长制式约1600字 / 短视频制式约500字·1.5分钟）。
- 每集≥2处有效反转，须过四条件（改变处境/有前置/不靠空投/有后续），伪反转不计数。
- 每场≥80%台词推动剧情且过三问（打人/挨打/递刀），≤20%留纯付息句；两指标一票不冲抵。
- 弹药每集3-5组，入库带元数据四项，无元数据不入库。
- 换场必须带来新角色/新证据/新压力源/新反转/新卡点之一。
- 集尾钩子=已成立的情绪应收账在即将变化时切断；禁切完成态、禁无关新事件硬续命、禁重复已解决问题。
- OS 每集≤3条每条≤2句；VO 默认禁用；电话远端声音一律 V0 化。

## 验收自检（交付前必做）
- **复述双轨测试**：轨一验情绪（对方"然后呢？"=走剧情重写；骂出声=通过）；轨二验因果（说清"想要什么→做了什么→逼出谁的选择"）。
- **三级自检**：每场（三问/密度/四问齐备/换场合法）→ 每集（弧线单/反转/钩子/记分牌/弹药/OS/主角在场/人设无漂移）→ 全剧（恨账逐笔清算/承诺全兑付/因果合规/认知仓位爆清/第20集起每集≥1次反派脸疼时刻/投流标题5条）。
- **四级修改**：句级→场级→集级→架构重写，发现结构病禁靠润色掩盖。
- **十大失效模式库**（事件堆砌/硬拽情绪/伪冲突/伪反转/模糊悬念/重复受虐/主角失踪/解释型台词/表面创新/表格型创作）见 `references/06`。

> 冲突裁决：第0章＞各章；第12-15章在其专属阶段对分集大纲有优先权。
