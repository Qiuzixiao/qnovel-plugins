第10章 创作流程

⓪过选题闸门（第12章）→ ①定核心燃料 → ②定情绪承诺与故事核（过2.1四问）→ ③定高概念与爽点引擎（过成立前提检查：甲式P1-P4/乙式Q1-Q4）→ ④定主角赢法 → ⑤定反派作恶逻辑+原型语录采集（≥20条附出处）→ ⑥建账本与清算表（主反派双付清、宽恕名额≤1）→ ⑦建弹药库（含元数据）→ ⑧排阶段大纲（以"人物选择+账户变化"为单位；过单案自查与区块规划）→ ⑧.5首集方案单独过十检（第13章）→ ⑨排分集卡点与反转位点，锁付费闸门位并倒排铺垫（第14章）→ ⑩建四张表（0.5节）→ ⑪分批写正文（格式守第9章、成本守第7章）→ ⑫验收（第11章+四表两单；不过按15.1四级修改处置）。

第11章 自检清单（验收期执行）

11.1 每场：
[] 逐句过三问（打人/挨打/递刀），无纯信息句
[] 逐句过九功能表：攻击/防守/诱导/争权/表态/试探/暴露欲望/改变关系/运输关键情报——纯信息句必须附着立场、目的或代价，否则删
[] 80%功能密度达标，纯付息句≤20%
[] 四问齐备：谁当面欺负主角/主角赢了哪回合/反派当场送了什么/有没有"脸"收据
[] 成交收据：权力、关系、条件或结果至少变一项，关键后果未被仓促跳过
[] 换场符合7.1；删除本场会损害因果、情绪或商业节点
[] 无重复上一场已得出的结论

11.2 每集：
[] 情绪弧线单一行填得出（合法内脏词+具体应收账款）
[] 单集≥2处有效反转（过5.3四条件，伪反转不计）
[] 集尾钩子属两类之一且形式合法（8.2两式，禁切完成态）
[] 记分牌被提醒或变动
[] 弹药3-5组；OS≤3条且合规
[] 主角在场合规；人设无漂移
[] 无巧合推进、无人物突然降智
[] 复述双轨测试通过

11.3 全剧：
[] 恨账表逐笔清算完毕，无坏账
[] 主承诺兑现，报价全部兑付；辅承诺未抢主线；核心卖点未换轨
[] 因果合规检验（0.6）：重大事件可由人物欲望和选择解释，无连续巧合，反转均有前置
[] 认知仓位表逐仓爆清，无悬空仓位（开图型项目另行报批）
[] 程序戏无伪装残留
[] 第20集起每集≥1次"反派当场脸疼"可视化时刻（羞辱感非进度感）
[] 投流标题5条已产出（每条≥3个天然流量词）；每个大冲突答得出"60秒素材评论区吵什么"
[] 情绪账目单与人物因果摘要可完整写出
