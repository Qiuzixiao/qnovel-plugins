# 单场与对白的视听化改写

## R — 原文（Reading）

> “台词只是辅助，不是用来解决问题的。”
>
> — 查理，《写好短剧》“对白创作技巧”

## I — 方法论骨架（Interpretation）

把每场戏视为一个小型冲突系统，而不是信息容器。先确定双方此刻想得到什么，再安排动作、阻力和状态改变；让场景本身提供可拍的视觉/听觉细节。对白只补充动作无法表达的内容，先写角色没说出口的潜台词，再压缩成口语。用信息差、正负极和动作进出制造起伏，删掉没有冲突、没有状态变化或不改变局面的句子。

## A1 — 书中的应用（Past Application）

### 姜文“听力障碍者钓鱼”对白

- **问题**：角色表面交流内容与真实目的不一致。
- **方法论的使用**：利用观众/角色的信息差和潜台词，让同一句话承担误导与推进。
- **结论/结果**：对白即使简短，也能有戏剧能量。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个 skill？

1. 一段戏“全是解释”，想改成可拍动作。
2. 两个角色对白干巴巴、问答过多，需要潜台词和冲突。
3. 想检查一场戏是否有状态变化、正负极和视觉细节。

### 语言信号

- “把这段对白改得更口语、更有潜台词”
- “这场戏不够有戏/不够可视化”
- “少说多做，帮我改成能拍的版本”

### 与相邻 skill 的区分

- 与 `short-drama-structure`：本 skill 改单场执行，不重新安排整部故事的 20 拍。
- 与 `short-drama-hook`：本 skill 处理场内表达，不负责分集钩子与高潮卡点。
- 与 `short-drama-revision`：本 skill 是局部重写；后者是全稿诊断排序。

## E — 可执行步骤（Execution）

1. **锁定场次目标与对抗**：写出双方目标、阻力、胜负变化；若没有变化，先建议删场或合并。
2. **视听化重写**：选择独特场景，补充可见动作/声音/道具，用动作进出切入切出，标记信息差方向。
3. **对白瘦身**：先写潜台词，再保留必要口语；删除重复问答、电话说明、无关动作，并复核开场/结尾状态是否不同。

## B — 边界（Boundary）★

### 不要使用

- 用户只需要整剧结构或分集卡点时。
- 纯文学散文、非影视文本，不强行套“可拍场次”。

### 失败模式

- 用对白解释并推动一切；电话、独白和问答替代行动。
- 场景没有核心冲突或状态变化。

### 作者盲点/局限

- “对白越少越好”更适合商业影视，不适用于语言本身是卖点的戏剧或实验文本。
