# 短剧格式规范（正文 + 大纲/集纲）

> 这是短剧创作里**最硬、可程序校验**的一层。违反任何一条，正文/大纲就不是合格短剧剧本。正文完整规范见 `references/正文写法规范.md`，集纲完整规范见 `references/大纲与集纲写法.md`。

## 一、正文固定骨架（锁定模板）
```
第N集

N-1 具体地点 具体时间 内/外
人物：人物甲、人物乙

△人物甲（动作行）
人物甲（表演提示）：台词。

【卡点特写：已经发生的具体结果 + 未解决的回应/选择/验证/后果】
【本集完】
```

## 二、集标题与场次头
- 集标题只能写 `第N集`，禁加「本集看点/创作说明/人物分析」。
- 场次头固定 `集数-场次 地点 时间 内/外`（例：`3-2 城南仓库 夜 内`），编号连续递增，地点/时间/内外景具体。
- 场次头下一行必须是 `人物：`，只列本场有对白的人物。

## 三、动作行（△）铁律
- 以 `△` 开头独立成行，结构：`明确主语 + 可执行行为 + 对象/环境 + 可见变化/下一作用`。
- 一行只保留一个行动主体和一个动作焦点；不同人物动作必须分行。
- 常规动作行 ≤30 有效字符，超 40 需重写/拆分（按动作意义重写，不机械截断）。
- 禁抽象心理/作者结论句（❌`△他意识到事情不对` ❌`△气氛变得紧张`；✅`△林夏攥紧缴费单`）。
- 禁无功能细节（无对象皱眉/点头/握拳/落泪；重复台词含义的动作；不影响剧情的走动喝水）。
- 动作功能三型：`plot_bearing`（推进）/ `performance`（表演）/ `transition`（过渡），每条须有独立作用。

## 四、台词铁律
- 普通台词 `人物甲：台词。`；带提示 `人物甲（压低声音，盯着文件）：台词。`
- 动作与台词拆行；括号内只放情绪状态词（急/愤怒/嘶吼），禁止动作进括号。
- 台词不能是「大纲改写成对白」，不能承担作者旁白。
- **知情边界**：人物只能说「已知内容 + 已发生素材事件 + 关系允许披露内容」，禁说只有作者/观众知道的信息。
- 锚点台词先落实，再补自然反应台词。

## 五、表演提示
- 写人物名与冒号之间，补神态/视线/身体/停顿/接收反应，必须是演员能完成的外在表现。
- 禁抽象结论（❌`（感到事情严重）`；✅`（手指停在屏幕上，抬眼看向对方）`）。
- 删除提示后，台词仍须符合人物设定。

## 六、OS / VO / 闪回
- **OS（内心独白）**：符合人物知情范围，后面必须有对应动作/台词/选择；禁替作者解释、禁提前泄露；**每集 ≤3 条、每条 ≤2 句**。
- **VO（画外叙述）**：默认禁用；仅时空连接/场外事件/必要背景/蒙太奇用，禁替人物总结心理。
- **V0**：电话及远端声音，功能角色一律 V0 化。
- **闪回**：必须独立成场（新场号），前有现实触发，内有动作+台词推进；`【闪回结束】`独立成行；回现实重建完整场次；禁闪回套闪回。

## 七、其他格式禁项
- 禁中文破折号；单集不以拟声词开头；无音效/BGM 标注；正文不标理论名称；不用小说式心理描写代替表演。

## 八、字数密度（软规则，立项参数决定制式）
- 长制式：每集 1200–2000 有效字符，目标约 1600。
- 短视频制式：约 500 字 / 1.5 分钟。
- **凑字数禁**：重复同义台词/重复动作/堆叠抽象心理/无意义走动喝水/旁白重复正文。
- **删字禁**：删掉必要的刺激/行动/反应/选择/结果/情绪过程。

## 九、大纲 / 集纲格式铁律
- **大纲（全剧）**：2–6 自然段，每段一个剧情阶段，段落间因果承接；纯第三人称叙事；覆盖 初始困境→引爆点→核心目标→阻力→升级→转折→最大危机→高潮→结局；禁分析性说明、空泛判断。
- **逐集集纲**：固定形态 `### 第N集` + 一句导语 + 一段完整故事（第三人称）；**默认不保留台词**，普通对白转成「交流行为 + 信息变化 + 即时反应 + 剧情后果」；每集最多保留一句剧情锚点台词（逐字存在于正文、不可替代）；禁人物名冒号台词、OS/VO/旁白标签、表演提示、动作括号、镜头指令。
- **集尾**：必须是「本集实际发生的最后一个具体事件」，禁抽象判断收尾，禁机械补造电话/黑影/敲门钩子。
- **导语**：公式 `核心人物/关系 + 最关键冲突/选择/反转 + 造成的压力或变化`；禁「本集看点是…」、人物台词、下集才发生的结局、未到揭示点的隐藏真相。

## 十、格式自检（生成后必做）
- 场景：进入原因？任务可验证？真实变化？下一步因果？
- 动作：明确主语对象？演员可执行？可见变化？无作者结论？
- 台词：符合身份关系目的？不越知情边界？推动行动而非复述大纲？
- 情绪：可观察行为呈现？影响后续？不单靠喊叫哭泣？
- OS/VO/闪回：OS 导致后续行为？VO 有叙事必要？闪回有触发和完整场？
- 素材连续性：落实集纲？没改变事实？没提前用后续结果？与上下集一致？
