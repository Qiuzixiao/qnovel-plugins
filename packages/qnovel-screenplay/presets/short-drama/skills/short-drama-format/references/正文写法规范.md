# DLKJB 短剧正文写法规范

## 1. 适用范围

本文只规定短剧正式正文的写法、排版和可表演化要求。

它不规定固定题材、固定人物类型、固定冲突模式、固定反转方式或固定结局。正文只能依据用户提供的素材创作；素材没有明确支持的事实、关系、能力、秘密和结果不得自行添加。

## 2. 正文写作总原则

短剧正文必须同时满足以下原则：

1. 剧情由人物的动作、台词、反应和选择推进。
2. 所有重要剧情都必须落到演员或镜头能够直接呈现的内容上。
3. 人物说话要符合人物设定、当前关系、当下目的和知情范围。
4. 情绪不能只用作者说明表达，要通过身体、神态、语气、停顿、行动和关系变化呈现。
5. 每场戏都要有进入原因、场景任务、真实变化和下一步因果。
6. 不能用概括性叙述替代完整的戏剧过程。
7. 写作要保留素材中的事件顺序、人物状态、关系变化和结果边界。
8. 细节服务于剧情、人物和情绪，不能用无功能动作或重复台词凑字数。

## 3. 固定正文格式

```text
第N集

N-1 具体地点 具体时间 内/外
人物：人物甲、人物乙

△人物甲接住刚刚发生的刺激，视线和身体位置出现具体变化。
人物甲（表演提示）：台词。

△人物乙接收这句话，改变动作、站位或下一步策略。
人物乙：回应台词。

【卡点特写：已经发生的具体结果，以及仍未解决的回应、选择、验证或后果。】
【本集完】
```

### 3.1 集标题

- 集标题只能写成 `第N集`。
- 不在正式正文中加入“本集看点”“创作说明”“人物分析”等内部内容。

### 3.2 场次头

场次头格式固定为：

```text
集数-场次 地点 时间 内/外
```

例如：

```text
3-2 城南仓库 夜 内
```

要求：

- 场次编号连续递增。
- 地点、时间和内外景要具体。
- 场次头下一行必须是 `人物：`。
- `人物：` 行列出本场实际参与对白的人物，不列只出现但没有对白的背景人物。

## 4. 场景写法

每场戏都按以下顺序展开：

```text
进入原因
→ 当前刺激
→ 人物接收和判断
→ 人物采取动作或开口
→ 对方回应
→ 策略、关系、信息、权力、选择或代价发生变化
→ 可见结果
→ 情绪余味和下一步因果
```

### 4.1 场景进入

开场要让观众知道人物为什么出现在这里、刚刚发生了什么，以及本场要处理的具体问题。

避免直接写：

```text
两人开始商量这件事。
```

应写成能够拍摄的进入动作、物件、位置或第一句台词，例如：

```text
△人物甲把文件推到人物乙面前，手指压住最后一页。
人物甲：你先看这里，再告诉我你还要不要签。
```

### 4.2 场景任务

场景任务必须是可验证的变化，例如：

- 让某人交出一件物品。
- 让某人改变一个决定。
- 让某段关系从疏离变为暂时合作。
- 让一个事实被确认或继续隐藏。
- 让人物付出具体代价。
- 让人物获得或失去一个行动条件。

不能只写“表现紧张”“推动剧情”“加强矛盾”等抽象任务。

### 4.3 场景转折

每场戏至少要有一次真实转折。转折前后必须能看出具体差异，例如：

- 说话策略改变。
- 人物从拒绝变为试探。
- 权力位置改变。
- 关系边界被触碰或重新建立。
- 选择成本增加。
- 某人得到新信息，或失去原有判断依据。
- 空间、道具或时间压力改变。

不能用一句“事情出现了转机”宣布转折，必须写出造成变化的动作、台词和接收反应。

## 5. 动作行写法

动作行以 `△` 开头，必须写演员或镜头能够直接执行的行为。

### 5.1 动作行的基本结构

```text
△明确主语 + 可执行行为 + 对象或环境 + 可见变化/下一作用。
```

例如：

```text
△人物甲抬手挡住门缝，没让人物乙看见里面的人。
```

### 5.2 动作行必须具备的要素

- 明确谁在行动。
- 明确对谁、对什么或对哪个空间行动。
- 明确动作本身。
- 明确动作造成的可见变化。
- 明确动作如何影响下一步。

### 5.3 动作行分行规则

- 一行只保留一个主要行动主体和一个动作焦点。
- 不同人物的动作必须分行。
- 刺激接收、策略变化、对方反应和结果落地通常应分别写行。
- 同一人物的连续动作只有在不可拆分且属于同一即时行为时才可合并。
- 不按字符数机械截断；要按动作意义重写。
- 常规动作行尽量控制在约 30 个有效字符内，超过 40 个有效字符通常需要重写或拆分。

### 5.4 动作行禁止事项

禁止用以下方式推进剧情：

```text
△他意识到事情不对。
△众人终于明白真相。
△气氛变得紧张。
△两人经过一番争论后达成一致。
△关系发生了变化。
```

这些句子包含不可见的心理、作者结论或压缩过程，应改写为具体动作、台词和反应。

以下内容也不能作为无功能细节反复使用：

- 无对象的皱眉、点头、握拳、落泪。
- 重复台词含义的动作。
- 不影响剧情的走动、喝水、环顾。
- 依靠“随即”“接着”“然后”连接的残句。

### 5.5 动作的功能类型

动作可以承担以下一种或多种功能：

- `plot_bearing`：直接改变剧情、选择、关系、信息或结果。
- `performance`：补充神态、视线、身体、停顿、空间或物件反应。
- `transition`：完成合法的时空衔接或场景过渡。

每条动作都应有独立作用，不能只作为装饰。

## 6. 台词写法

### 6.1 台词格式

普通台词：

```text
人物甲：台词。
```

带表演提示的台词：

```text
人物甲（压低声音，盯着文件）：台词。
```

### 6.2 台词的剧情功能

台词可以用于：

- 提出要求。
- 回应刺激。
- 隐瞒或试探。
- 拒绝或让步。
- 争取时间。
- 改变行动条件。
- 触碰关系边界。
- 暴露情绪变化。
- 促成选择或制造新的后果。

台词不能只是把大纲改写成对白，也不能承担作者旁白的工作。

### 6.3 锚点台词与反应台词

每个素材要求的关键内容先落实为锚点台词，再补充自然反应台词。

反应台词可以表现：

- 接话。
- 迟疑。
- 打断。
- 回避。
- 嘴硬。
- 改口。
- 情绪泄漏。
- 关系修复。
- 重新提出条件。

反应台词必须属于当前交锋，回应同场前面已经发生的刺激，不得借机增加素材没有的新事实。

### 6.4 台词活人感

人物台词要体现人物在当前关系和压力下的具体说话方式：

- 熟人之间可以省略彼此都知道的背景。
- 不同关系对象使用不同称呼、距离和说话策略。
- 人物可以答非所问、回避重点、先反问再回答或说到一半改口。
- 情绪变化应影响句长、语气、停顿、信息顺序和解释意愿。
- 受压时不应所有角色都变成同一种激烈表达。
- 台词不必句句完整、工整或书面化，但必须清楚、可演、符合人物身份。

### 6.5 台词知情边界

人物只能说出：

```text
人物已知内容
+ 当前已经发生的素材事件
+ 当前关系允许披露的内容
- 当前场景禁止透露的内容
```

不能为了让台词更聪明，让人物说出只有作者或观众知道的信息。

## 7. 冒号前表演提示

表演提示写在人物名和冒号之间，主要用于补充：

- 神态。
- 视线。
- 身体状态。
- 说话动作。
- 停顿。
- 接收刺激后的即时反应。

示例：

```text
人物甲（压住慌乱，迅速收起手机）：我没说过这句话。
```

表演提示不能写成抽象结论，例如：

```text
人物甲（感到事情严重）：……
```

应改为演员能完成的外在表现：

```text
人物甲（手指停在屏幕上，抬眼看向对方）：……
```

表演提示不能替代台词风格。删除提示后，人物台词仍需符合人物设定、关系和知情范围。

## 8. OS 的写法

OS 是人物没有说出口、但会推动同场后续行为的心理活动。

OS 不是每场必有，也不是通用情绪标签。

### 8.1 适合使用 OS 的情况

- 人物基于误会作出后续行动。
- 人物面对明确选择，需要让观众理解其行为逻辑。
- 配角对某人的态度正在转变，需要表现中间判断。
- 人物不能直接说出真实想法，但该判断会立刻影响行动。

### 8.2 OS 的硬约束

- 必须是当前人物的主观判断。
- 必须符合人物当下知情范围。
- 后面必须有对应的动作、台词或选择。
- 不得替作者解释剧情。
- 不得概括已经可以由动作呈现的过程。
- 不得提前泄露人物不可能知道的事实。

格式示例：

```text
人物甲（OS）：他现在不敢报警，手机一定还在身上。
△人物甲趁人物乙转身，伸手去够桌边的手机。
```

如果人物心理能够通过当下台词、表演提示和动作自然呈现，就不强行加入 OS。

## 9. VO 的写法

VO 是有叙事必要的画外表达，和 OS 不同。

VO 可以用于：

- 时空连接。
- 场外事件传递。
- 必要背景补充。
- 蒙太奇或连续行动的连接。
- 素材明确要求的叙述内容。

VO 不得用于：

- 替人物总结心理。
- 替动作概括过程。
- 替作者宣布关系变化。
- 提前透露未来真相。
- 解释本应由演员完成的情绪和行动。

格式示例：

```text
人物甲（VO）：三天后，所有人都收到了同一张照片。
```

如果内容可以由镜内台词、动作或场景完成，就不使用 VO。

## 10. 情绪表达

情绪必须通过可观察变化呈现，而不是直接写“他很愤怒”“她十分悲伤”。

可以从以下方面表现：

- 身体控制变化。
- 视线和站位变化。
- 说话速度和句子长度变化。
- 停顿、打断和改口。
- 对物件的处理方式变化。
- 对关系对象的称呼变化。
- 由防御转为攻击，或由强硬转为退让。
- 做出选择时承担的代价。

每场情绪至少要有两个连续阶段，并说明前一阶段如何导致后一阶段的台词、动作、关系或选择变化。

情绪表达要避免：

- 只写情绪标签。
- 每个人都用喊叫表达激烈情绪。
- 用哭、怒吼、握拳反复代替细腻变化。
- 情绪变化没有后续行为影响。

## 11. 配角和临时人物

配角不应只作为背景板出现。

如果配角在本场实际影响了：

- 选择。
- 压力。
- 条件。
- 结果。
- 信息接收。
- 人物关系。

就必须通过独立动作或台词留下可验证贡献。

临时人物只按当前场景需要授权：

- 报信、播报或口令人物通常只承担一句功能性台词。
- 会改变条件、选择或结果的临时人物，需要明确场景权限和知情范围。
- 不因临时出场就擅自补造其长期性格、经历或固定口头禅。

## 12. 闪回正文写法

闪回要当作一次新的场景书写，不用一段作者叙述带过。

```text
当前场景中的具体触发动作或台词。

【闪回】

N-M 过去地点 过去时间 内/外
人物：人物甲、人物乙
△过去事件中的具体动作。
人物甲：过去事件中的台词。
△人物乙接收并造成新的可见变化。

【闪回结束】

N-M 当前地点 当前时间 内/外
人物：人物甲、人物乙
△人物从闪回结果中恢复，并采取下一步行动。
```

要求：

- 闪回前必须有现实场景触发。
- 闪回使用新的连续场号。
- 闪回内部仍然由动作和台词推进。
- `【闪回结束】` 必须独立成行。
- 回到现实后必须重新建立完整场次。
- 不允许闪回套闪回。

## 13. 字数、节奏和细节密度

默认每集正文控制在 1200—2000 个有效字符，目标约 1600 字。

字数不足时，应优先补充：

- 事件的完整过程。
- 人物接收和反应。
- 关系互动。
- 真实的策略变化。
- 必要的动作和空间细节。
- 情绪转折和结果余味。

禁止用以下方式凑字数：

- 重复同义台词。
- 重复相同动作。
- 连续堆叠抽象心理。
- 无意义走动、喝水、环顾。
- 旁白重复正文已经展示的内容。

字数超出时，应优先删除重复和低收益表达，不能删掉必要的刺激、行动、反应、选择、结果和情绪过程。

## 14. 正文自检清单

### 场景层面

- 场景是否有明确进入原因？
- 本场任务是否可以通过正文验证？
- 是否发生了真实变化？
- 场尾结果是否造成下一步因果？

### 动作层面

- 每条动作是否明确主语和对象？
- 演员是否能够直接执行？
- 是否写出了可见变化？
- 是否存在作者结论或抽象心理？
- 是否有重复、无对象或无功能动作？

### 台词层面

- 台词是否符合人物身份、关系和目的？
- 人物是否说出了当下不该知道的内容？
- 是否存在接收、迟疑、打断、回避或改口？
- 不同人物是否有可区分的表达方式？
- 台词是否在推动行动，而不是复述大纲？

### 情绪层面

- 情绪是否通过可观察行为呈现？
- 情绪变化是否影响后续台词或动作？
- 是否避免用单一的喊叫、哭泣或愤怒代替全部情绪？

### OS、VO 和闪回

- OS 是否真正导致了后续行为？
- VO 是否确有叙事必要？
- 闪回是否有具体触发和完整场景？
- 闪回结束后是否重新建立现实场次？

### 素材和连续性

- 是否完整落实了当前集纲和相关大纲内容？
- 是否改变了人物、关系、事件或结局事实？
- 是否提前使用了后续剧情结果？
- 是否与上一集状态和下一集承接点一致？

## 15. 正文最终标准

一份合格的短剧正文应当让读者能够直接回答：

- 谁在什么地方、什么时间行动？
- 他为什么在此刻做这个动作或说这句话？
- 对方如何接收并回应？
- 人物的策略、关系、选择、信息或代价发生了什么变化？
- 观众能够看到什么具体结果？
- 这一结果如何推动下一场或下一集？

如果这些问题只能依靠作者解释、剧情概括或额外说明才能回答，正文就还没有完成可表演化改写。
