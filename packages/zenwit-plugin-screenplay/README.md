# 短剧创作

把「短剧创作」Agent 预设与整套技能装进桌面端。选中它，助手就按短剧编剧的方式工作：从立项选题到成片交付，一条完整流水线。

## 它能做什么

- **11 个技能**：总纲·情绪账务引擎、立项选题、人物骨架、结构、分场、正文格式、改稿、钩子、交付、技能沉淀、文件组织；
- **立项参数表**：立项时逐项确认并落进项目 `创作合同/`；
- **格式自检脚本**：正文格式一键自检；
- **完整 Agent 能力**：预设组合派生自运行时自带的标准预设，压缩上下文 `/compact`、计划模式、目标、子代理、待办、后台任务、项目指令等一并继承。

创作方向始终由你决定：路径、文件名、标题、篇幅、格式都以你的要求为准；它只在真正影响结果的分歧上问你一次。

## 运行位置与依赖

- **只有 Host 半，没有界面**：插件在后台把随包预设装进应用数据目录的 `.agent-presets/zenwit-plugin-screenplay/`，界面由应用自带的预设选择器提供；
- **组合派生自运行时**：读取运行时自带的标准预设，只改 persona 文案与技能目录两处，其余行原样继承——运行时新增工具或命令会自动出现在本预设里；上游缺行时报错并保留原有预设，不会降级成缺能力的预设；
- **不需要注入任何能力**：插件不声明 `inject`，只解析应用数据目录、并在其中维护这一份预设；
- **不引入第三方运行时依赖**：组合里只有运行时自带的插件行（文件、搜索、shell、联网、提问、技能）；
- **不覆盖别人的预设**：安装的目录带归属标记 `.managed-by`；同名目录若来自其它来源则拒绝覆盖、卸载时也不删除；写入走临时目录 + 原子替换，应用与命令行同时运行不会留下半份预设。

## 安装

在插件市场搜索「短剧创作」安装，重启后进入应用，在预设里选择 **短剧创作**，把项目目录交给它即可。卸载插件时，它会把自己安装的那份预设一并移除。

## 开发

```bash
corepack yarn workspace zenwit-plugin-screenplay check   # 构建 + 类型检查 + 单元测试
```

发布前校验派生结果：与上游行集合对比 + 用真实内核 schema 逐行校验配置（缺必填字段只会在挂载预设时报错，这一步能提前发现）：

```bash
ZENWIT_KERNEL_MODULES=<内核 node_modules 路径> yarn workspace zenwit-plugin-screenplay verify:composition
```

预设资产（技能、参数表、自检脚本）在 `presets/zenwit-plugin-screenplay/`——纯文件，改完即生效。`agent.cordis.yml` 不随包提供：`src/index.ts` 在安装时从运行时标准预设派生它，只改 persona 文案与技能目录两处，路径按实际安装位置写入。
