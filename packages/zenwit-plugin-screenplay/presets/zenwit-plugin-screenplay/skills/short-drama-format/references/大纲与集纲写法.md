# 大纲与集纲写法

## 一、总原则

大纲和集纲都必须以剧本正文已经发生的事件为依据，写清人物、行动、冲突、变化和结果。文字应当像一篇完整、清楚的故事简介，而不是分析报告、创作建议或剧情要点清单。

两者的区别是：

- **大纲**概括全剧的主线发展，回答“整个故事如何开始、升级并收束”。
- **集纲**讲述单集的完整故事，回答“这一集具体发生了什么，以及本集最后停在哪里”。

不得用空泛判断代替剧情，例如“矛盾不断升级”“局势越来越复杂”“主角开始反击”。这些判断必须落到具体人物、具体行动和具体后果上。

## 二、全剧大纲的写法

### 1. 整体结构

大纲应围绕全剧主线形成一条连贯的因果链：

**主角初始处境 → 故事引爆点 → 核心目标 → 主要阻力 → 矛盾升级 → 关键转折 → 最大危机 → 高潮解决 → 人物与关系结局**

不需要把每一集逐一复述，也不能把各集内容机械拼接。应当提炼推动全剧向前发展的关键阶段，每个阶段都要说明：

- 进入这一阶段时人物和局势是什么状态；
- 主角当前想完成什么；
- 对手或外部环境通过什么方式阻止主角；
- 哪些关键事件改变了目标、关系、信息、资源、权力或危险程度；
- 这一阶段以什么结果结束，并为什么进入下一阶段。

### 2. 必须写清的内容

大纲正文应当完整覆盖：

- 主角的初始困境和核心诉求；
- 引发主线的关键事件；
- 主要对抗关系和阻力来源；
- 重要身份、秘密、证据或信息的揭示；
- 主要人物关系从建立、变化到最终状态的过程；
- 核心看点造成的主角态度变化、决定和行动；
- 重要配角如何通过选择和情绪推动主线；
- 必要的时间跨度、时间锚点以及插叙、倒叙、闪回对主线的影响；
- 最大危机、高潮行动、矛盾结果和正文真实结局。

### 3. 段落和语言

大纲通常写成 **2—6个自然段**，每段概括一个剧情阶段或一组紧密相连的阶段。段落之间要有因果承接，不能变成事件罗列。

大纲使用第三人称叙事，直接讲人物如何行动、冲突如何变化和结果如何产生。不要出现“故事在这里完成了第一次升级”“本阶段的看点是”等分析性说明，也不要写剧本之外的评价和设计。

大纲的结尾必须落到主要矛盾的解决、人物终局、关键关系终局和正文最后事件。不能用尚未发生的规划性结局替代剧本中的真实结局。

## 三、逐集集纲的写法

### 1. 固定形态

每集由一条导语和一段完整故事组成：

```markdown
### 第1集

导语：用一句话直接写出本集最核心的冲突、选择、反转或关系变化。

正文用第三人称讲完这一集从开场到真实结尾发生的完整故事。
```

集纲不是把“本集内容、核心冲突、关键推进、核心看点、集尾钩子”等字段拼成一段话，而是要像讲述一集完整的故事一样自然展开。不得在正文中使用这些分析标签。:codex-annotation{index="1"}

### 2. 故事推进结构

集纲正文按照剧本的呈现顺序，完整写出：

**开场处境 → 触发事件 → 人物目标或即时诉求 → 人物行动 → 阻碍与对抗 → 冲突升级 → 关键转折 → 主角态度或关系变化 → 阶段结果 → 真实集尾事件**

不是每个环节都必须单独成句，但不能删掉让后续剧情成立的因果桥梁。每个重要事件都要写出人物、动作、对象、原因和结果。

### 3. 内容取舍

必须保留：

- 改变人物目标或行动方向的事件；
- 改变身份、关系、信息、资源、权力或危险程度的事件；
- 导致误会、反转、冲突爆发或结果兑现的关键动作；
- 对话引发的决定、反应和剧情后果；
- 为本集结尾成立所必需的前置事件；
- 本集最后一个真实事件。

可以压缩：

- 不改变剧情状态的重复争执；
- 同义反复的对白和语气词；
- 不影响因果的寒暄、走位和环境描写；
- 已经由一个代表性动作充分表达的重复反应。

压缩只能合并重复内容，不能把不同结果的事件压成“双方发生争执”这类笼统表述。

### 4. 具体程度

集纲不能只说“主角受到打击后反击”，而要说明：谁带来了什么刺激，主角如何判断，随后决定做什么，以及行动造成了什么结果。

不能只说“人物关系恶化”，而要说明双方原本是什么关系，哪件事造成变化，关系变成什么状态，以及这种变化怎样影响后续行动。

不能只说“配角很生气”，而要说明配角为何产生情绪、通过什么可见动作表现、情绪指向谁，以及它如何施压、支持、激怒或唤醒主角。

## 四、导语的写法

导语负责为单集定调，直接写出当前剧集最值得看的具体事件。推荐使用：

**核心人物或核心关系 + 最关键冲突、选择或反转 + 造成的压力或变化**

导语应当简洁、明确、有事件依据，不能写成宣传口号。不得出现：

- “本集看点是……”；
- “高能不断”“危机即将展开”等空泛卖点；
- 人物台词；
- 下一集才发生的结果；
- 尚未到揭示节点的隐藏身份或真相。

导语只负责点出核心看点，不能替正文承担剧情信息。正文仍必须完整讲清看点发生的前因、过程和即时后果。

## 五、插叙、倒叙与闪回的写法

必须保留剧本原本的叙事呈现顺序，不能为了让故事更顺而改写成顺叙。

### 插叙

写清：

**现实主线开始 → 从现实进入过去或背景事件 → 插入事件完整发生 → 回到被打断的现实节点 → 现实主线受到的影响**

不能只写“穿插回忆”或“补充往事”，必须说明插入了什么以及回来后现实发生了什么变化。

### 倒叙

先写故事时间较晚的结果、危机或场面，再用“时间回到……”等自然表达回到较早时间，按照剧本已经展示的部分继续讲述。不能提前写出本集尚未展示的追赶结果。

### 闪回

写清现实中的触发点、过去发生的内容、回到现实的位置，以及这段过去如何改变当前人物的认知、态度或行动。

### 其他画面载体

如果剧本使用快闪、蒙太奇、交叉叙事或插入画面，应在故事中自然写出：

- 快闪呈现了哪些已经发生的短事件及共同情绪；
- 蒙太奇覆盖了多长时间和哪些重复行动；
- 交叉叙事中两条线索如何同时推进；
- 照片、手机、档案、监控或其他物件承载了什么信息。

不得使用镜号、方括号、制作指令或凭空增加画面事件。

## 六、人物关系与主角态度

人物第一次进入当前因果链时，要交代读者此刻必须知道的关系。若真实关系承担后续反转，只写当前已经公开的表层关系，不能提前泄露秘密。

关系变化要写出：

**变化前状态 → 触发事件 → 变化后状态 → 对后续剧情的影响**

主角态度变化要写出：

**变化前态度 → 刺激事件 → 变化后态度 → 主角决定 → 具体行动**

“主角意识到真相”“主角态度转变”“主角更加坚定”等表述，只有在同时写出刺激、判断和行动时才算完整。

## 七、普通台词的叙事化写法

集纲默认不保留人物台词。普通对白应转换成交流行为、信息变化、即时反应和剧情后果。

例如，不写：

> 甲质问：你为什么一直瞒着我？

应写成：

> 甲追问乙隐瞒真相的原因，迫使这段长期被回避的关系矛盾公开化。

不写：

> 乙告诉甲自己已经查到真相，并要求甲相信她。

应写成：

> 乙拿出调查所得的证据，使甲确认此前的怀疑，并改变了原本的行动计划。

每集最多保留一句剧情锚点台词。锚点台词必须逐字存在于正文，并且对身份揭露、关系决裂、重大反转、核心立场或真实集尾不可替代。它只能自然嵌入第三人称叙述，不能恢复成“人物名：台词”的剧本格式。

集纲中禁止出现：

- 普通人物对白；
- 人物名加冒号的台词格式；
- “某人说/问/喊，后面接近似原话”；
- OS、VO、旁白标签；
- 表演提示、动作括号和镜头指令；
- 未登记的引号内容。

## 八、集尾钩子的写法

集尾必须对应剧本中本集实际发生的最后一个事件。有效的结尾应当写出：

**谁做了什么 → 对什么对象做 → 当场造成什么后果 → 留下什么真实问题**

适合落在结尾的具体事件包括：推门、敲门、电话接通、证据出现、身份被认出、攻击发生、逃离、死亡、物件落桌或人物作出不可逆决定。

不能用“局面失控”“矛盾恶化”“主角开始怀疑”作为最后一句，因为这些只是抽象判断，不是具体集尾事件。

如果原剧本结尾只有阶段结果，就如实收束；如果没有明确悬念，不得补造电话、黑影、敲门、证据或话说一半等机械钩子。也不能提前写出下一集才会揭晓的答案。

## 九、成稿语言要求

- 使用纯第三人称叙事；
- 直接写人物、动作、对象、原因和结果；
- 让冲突、看点和钩子通过事件自然呈现；
- 大纲写全剧阶段，集纲写单集完整故事；
- 不使用分析字段、评论口吻或创作过程说明；
- 不添加剧本中不存在的人物、关系、动机、事件和结局；
- 不用流畅的空话掩盖时间线、人物关系或因果缺失。
