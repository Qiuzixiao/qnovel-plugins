第1章 情绪承诺

全剧向观众承诺一种核心兑现，主承诺唯一，辅承诺≤2：出气 / 逆袭 / 查真相 / 修复遗憾 / 看坏人付代价。立项即锁死，每集向主承诺供血。承诺即债务：第1集立约，全剧分期兑付，大结局清账。

主角动机时限：第一集让观众感知主角当前欲望或困境；前3集锁定主要目标；目标绑定男频及通用大众情感（钱、权、出气、逆袭、看坏人付代价，P级默认）；后续行为持续受目标约束。

第2章 核心燃料

燃料=观众自己生活里的不爽。只从现实采集，不许凭空造：血缘偏心与亲情辜负 / 血汗钱被夺 / 被身份羞辱（穷、职业、学历） / 好心被欺与道德绑架 / 被宰被骗 / 权力与规则压迫 / 家产被亲戚觊觎 / 正义失灵坏人逍遥。测试标准：把燃料讲给目标观众听，对方能立刻接一句自己的亲身经历，才算点着。

2.1 故事核公式：故事核＝持续制造冲突的设定＋欲望明确的人物＋可投射的情感锚点＋明确兑现预期。
四问齐备才进分集：什么规则或处境会不断制造冲突？谁必然会撞上它？观众把自己的哪种生活经验投射进去？观众最终在等谁得到什么、谁失去什么？

2.2 创新原则：不刻意创新。不必规避同类题材，核心燃料点着即可反复强化已验证设定；禁止为与众不同增加理解成本。创新落点限定在：人物身份组合、关系结构、冲突场景、赢法、兑现方式、标志性道具或视觉动作。至少留一个可传播的差异化钩子。

第3章 压力源与反派

3.1 压力源常用型：身份碾压、道德绑架、诬告泼脏水、财产侵夺、当众羞辱、亲情胁迫、伪法律话术、舆论围攻、物理胁迫、得寸进尺。每个反派主用1-2型，压力话术必须有现实原型出处（新闻/亲历/评论区/真实纠纷），采集真实语感，不照搬具体作品台词。

3.2 反派书写三律：①反派还原观众身边的现实压迫者，优先沾亲带故；②反派是"蠢而自信地冲向铡刀"，强度在嚣张不在能力——嚣张的蠢货每赢一场观众多攒一分期待；③反派每开一次口、动一次手，必须给自己加一条罪或吃一次亏（自毁引擎，当场可见，不许延期三十集兑付）。

3.3 受害者反咬条款：被骗/被救的受害者必须亲手攻击拯救者，咬点必须是"拯救行为本身"，语料用反智原话。债务转记规则见0.4配套裁定。

3.4 单一主反派条款：付费闸门之前，一切矛盾归拢至单一主反派（或同一反派阵营账户），杂鱼恶行须能记到主反派名下。

3.5 反派动机条款：见0.6因果合规检验第二条。

3.6 验收宽标准：生成期口令仍是"每开口必加罪或吃亏"；验收期按"每次重要出场至少完成一项：加重责任/暴露欲望/升级手段/改变权力/制造新代价/吃到阶段性后果"判定，不因个别过场句枪毙整场。重复同一句羞辱而无增量=无效加账，删。

第4章 主角

4.1 主角替观众做事：观众不敢怼的他怼，观众咽下的他讨回来。主角是观众的优越感化身，不是焦虑化身。

4.2 尊严条款（H级不降）：主角可以输局面，不能输尊严。局面受挫时姿态纹丝不动，一句冷话转身走；禁止当众社死、狼狈、哀求；不能长期失去行动权。配套解释：物理压强（甲式"主角真挨打"）与尊严条款并行——肉身可损、姿态不弯，挨打不等于哀求。

4.3 姿态细则：无视律与双频姿态（0.4第3、4律）。主角冷判决台词限量：每集≤1句，情绪压到顶才放。

4.4 在场条款：主角不得连续2集下线（P级；双主角/群像特批豁免记工单，且必须有人继续承载核心情绪承诺）。主角缺席的集，情绪弧线单必须写明"观众在替主角等什么账"。

4.5 人设落地：见0.6——人设来自选择，不靠自我介绍。

第5章 翻转术

5.0 反转账务总则（旧引用"Skill A 5.0感知反转层"读作本节）
观众与场内角色各持认知仓位，反转＝强平重建仓，打脸＝反派认知仓位的当众爆仓。负反转存债，正反转付息兑付。每集结尾生成问题："这集哪个反转切一半？"（卡点=未完成的反转）。仓位排期以0.5认知仓位表为准。

5.1 常用八型：原话回收 / 身份反转 / 证据反转 / 阵营反转 / 结果反转 / 惩罚对位 / 当场自毁 / 外援反转。

5.2 翻转的账务本质：每次翻转必须清算恨账表上已登记的至少一笔，且观众能认出"这笔是第几集存的"。

5.3 反转成立四条件（验收用）：①改变人物处境或观众判断；②有前置线索或人物因果；③不依赖作者临时空投；④产生后续影响。只把一句话否定掉不构成反转；梦境、误听、假画面撤销结果＝剪辑欺诈，非法。

第6章 爽点引擎与信息差

6.1 引擎清单（每剧主引擎唯一+机制引擎≥1）：延迟验证（甲式变体：负反转节拍器）/ 秩序显影（乙式变体：验证"规则认不认他"）/ 反派自毁 / 账本回收与原话回收 / 公共审判 / 专业碾压 / 双杀高概念 / 竞拍加注 / 帮凶反噬。

6.1.1 系统级条款五条：
- 反派摇人律：验证者与清算力量必须由反派亲手召唤——审判庭由被告搭建，钟由被告敲响，主角零动作。
- 双帧对撞：开场3秒两个互斥形象怼脸（迎驾豪车鞠躬→推洗衣筐的老头）。
- 代价外包：主角只报价、警告、允许，执行外包给下属/反派家长/对方的傲慢；甲式外包理由=誓言与合规，乙式=逼格。
- 架空机构化：权力体系一律架空命名，换取合规与逻辑自由度。
- 估值反转【暂行定义，待补出处】：同一标的的估值被当众重估（8块的金针菇↔两万的牛肉），物值反转的账务学名。
  
6.2 信息差四摆法：
- 摆法一：观众+主角持牌，反派不知——延迟验证基座，主用。
- 摆法二：观众独知，全员不知——只准短悬念（≤1集揭牌），禁模糊悬念；每段剧情给观众明确期待感。
- 摆法三：观众+反派持牌，群众不知——反派每场公开表演都是被主角捏着演的，同一镜头双重爽点，单位成本最低。配合公私双刀律。
- 摆法四：观众+主角+亲人持牌，反派与群众不知——亲人暗醒后升格为"潜伏的牌"，反派每次自以为的收割都是被反向欺骗。
