第7章 压爽循环与场景

7.1 换场条款：换场必须带来新角色/新证据/新压力源/新反转/新卡点之一，否则搬回原场景写。

7.2 一景到底优先：情绪只有在跑不掉的空间里才会积压。转场即泄压阀，时间跳跃即泄压阀。默认"区块制"——一口锅（单场景+实时连续）熬干一个情绪段落再换锅。区块经营细则（甲式：舞台经营学六律+区块级三一律；乙式：电压经济学+标准化循环）。

7.3 弹药：一组弹药=一次可执行的压或爽的最小素材（一句反派原话、一个自毁动作、一笔可回收的账、一个社死道具）。配额：每集3-5组；全剧≥80集制式下总量≥240-400组。立项期建弹药库，反派台词从原型采集单组装。弹药入库须标注元数据四项：谁发动/为什么发动/改变什么/对应恨账表哪笔账。无元数据不入库。

第8章 卡点

8.1 卡点八型（仅用于大纲/集纲标注，正文禁标）：
A 反派突破底线 / B 灾祸坠落 / C 得意报应同框 / D 主角反常之举（配"啊？"信号）/ E 底牌将亮未亮 / F 阵营反水 / G 露马脚 / H 外援进门半句话收。

8.2 切点纪律（一票否决级）：每集结尾具体收法两式（禁切完成态，必须切在下一笔债的开口处；删五行自检法）。

8.3 集尾钩子内容两类：危机悬念/即将打脸，详见14.3。与8.2为内容×形式关系。钩子的本质：已经成立的情绪应收账，在即将变化时切断。切点前必须让观众知道自己在等什么；禁用无关新事件硬续命；禁重复本集已解决的问题。

第9章 台词与正文格式

9.1 格式基础
- 场景头：集-场 场景、日/夜、内/外。人物：
- 动作行：△开头独立成行，≤15字为佳，必须有物理结果，不写抽象心理判断，不堆砌文学修辞；打击类允许一个夸张后果词（旋转两圈、炸碎、倒飞）。
（错误：△林夏感觉自己的尊严受到了践踏。 正确：△林夏攥紧缴费单。）
- 台词行：只写"角色名：台词"，动作与台词拆行；括号仅限情绪状态词（急/愤怒，嘶吼），禁止动作入括号，动作一律走△行。
- 声音制式：OS=内心独白（每集≤3条、每条≤2句，只服务信息差或笑点，禁抒情、禁回顾总结、禁解说处境、不得代替行动）；VO=画外叙述（默认禁用）；V0=电话及远端声音（功能角色一律V0化）。
- 禁中文破折号；单集不以拟声词开头；无音效BGM标注；正文不标理论名称；不用小说式心理描写代替表演。
- 单集体量：约500字/约1.5分钟（老板锁死制式）。
  
9.2 台词功能密度律（80%律）
短剧正文只由动作行+台词行构成，动作极简，叙事重担全压在台词上。每场戏≥80%的台词必须推动剧情（改变账户状态、运输关键信息、完成反转），且这些句子同时须过0.1三问——信息塞进攻击里运输，不许裸奔。≤20%配额留给纯付息句。两个指标一票不冲抵：密度够但句句纯信息＝不过三问，照删；句句锋利但账户没动＝不过密度，重写。

9.3 台词病根条款
台词是人物动机与行为的外化。写不动先查四件事：人物想要什么、想逼对方做什么、为什么现在说、承担什么风险。禁止堆修辞救台词，不为金句破坏人物当下目的。通俗与否不看词汇粗浅，看观众能否迅速判断：谁在压谁、谁想得到什么、这句话逼对方做什么、说完局面变了什么。

9.4 信息运输五式（背景信息禁止成段宣讲）
一、带立场说信息："爸出钱买的房，你凭什么改成你儿子的名字？"
二、带条件说信息："还有三天，你拿不出货，就按合同赔六十万。"
三、带旧账说关系：一句称呼+一句旧账。
四、带选择说规则：人物因规则被迫选边，不安排讲解员。
五、带结果解释专业：先见后果，再补最少量解释。

9.5 关键数字与记分牌（E级默认）
关键数字必须：首次出现清楚可听、与人物利益直接相关、关键节点变体提醒、兑付时与前文对位。"两个角色各说一次"为默认做法，按记忆难度豁免记工单。重复只用于强化记忆点。钱留零头（83580，零头即真实感），指标卡线（高压160）。
