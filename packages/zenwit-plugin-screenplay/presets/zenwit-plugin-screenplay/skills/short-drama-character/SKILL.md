# 主角—反派—配角的压力与成长校验

## R｜原文依据

- 《开始创作·人物》要求主角有原始诉求、主动解决核心问题，并在压力下完成可见成长；高潮不能靠配角或巧合代打。
- 同章提出“中性事件”：好人与反派面对同一事件作相反选择，反派动机要在自身理论里自洽。
- 书中强调反派要“强大到跟主角势均力敌”，有具体、逐步推进的行动计划，通常先完成最后一步前的大部分。
- 修改清单指出配角行为必须合理化、人物设定要在剧情中兑现；无功能配角应合并或删除。

## I｜方法解释

把人物诊断做成四张互相咬合的表：

1. **主角发动机**：缺失/原始诉求 → 可量化目标 → 主动行动 → 失败代价 → 价值或行为转变。
2. **反派压力线**：反派信念 → 分阶段计划 → 每阶段能力/资源升级 → 对主角造成更坏处境。
3. **中性事件镜像**：同一无道德预设的事件，记录双方选择及其理论依据，确保冲突来自价值与策略，而非降智。
4. **配角功能网**：每个配角对主角当前目标是帮助、阻碍、诱惑还是见证；行为必须有动机并改变局面。

## A1｜书中案例

- 《我不是药神》把主角从逐利小市民推到愿意赔钱救人的“药神”，并用警察、同行、药监局、海关等多股现实压力替代脸谱反派。
- 章鱼博士、灭霸被用作强反派范例：目标清晰、行动按阶段推进，主角往往在对手完成计划最后一步时阻止。
- 书中以“肥皂泡/龟壳”说明激励事件要戳破主角妥协的保护壳，使其不得不行动。

## A2｜未来触发与区分

当用户说“主角太被动”“反派像工具人”“配角太多”“人物没有成长”“两人目标相同怎么成为对手”时调用。它负责人物因果、压力和成长，不负责设计首屏信息差/卡点（交给 `short-drama-hook`），也不负责把冲突写成具体动作对白（交给 `short-drama-scene`）。

## E｜执行步骤

1. **填主角表**：写出缺失、原始诉求、终局目标；逐集标记主角主动动作、失败代价和一次不可逆选择。若高潮解决来自配角/巧合，改为主角掌握关键信息并承担代价。
2. **建反派压力表**：写反派自洽信念及 3–5 步计划；每步至少夺走主角一种资源或升级风险，并让反派先完成大部分计划。检查双方能力、情报和资源是否势均力敌。
3. **做中性事件测试**：设计一个不预设善恶的事件（例如同一笔钱、同一名伤者），分别写主角与反派的选择、理由和后果；若选择无差异，补价值冲突或重写对手。
4. **清理配角与成长**：给每名配角标注功能、动机、首次/最后兑现点；合并只提供信息却不改变局面的角色。用“前态—受压—选择—后态”写成长证据，避免只写台词宣告。

## B｜边界与失败模式

- 不把“完整成长”当成所有喜剧、单元剧或反英雄题材的固定结局；但必须出现可观察的前后差异。
- 反派强不等于无敌或纯恶；需要可追踪计划、合理资源和能被主角在最后关键步骤阻止的窗口。
- 配角并非只能服从主角；其独立欲望可以制造阻碍，但必须回扣主线并合理化行为。
- 若用户只要求开场悬念、反转或付费卡点，转交 `short-drama-hook`，避免扩大范围。

## 相关 skills

- `short-drama-hook`：把人物压力转为观众可验证的悬念与卡点。
- `short-drama-structure`：把人物缺失、激励事件、两难和成长安排到四幕拍点。
- `short-drama-revision`：在全稿层面复核人设兑现、配角数量与主角主动性。
