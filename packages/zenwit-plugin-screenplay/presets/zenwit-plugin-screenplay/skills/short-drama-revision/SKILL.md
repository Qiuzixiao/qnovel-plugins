# 70 项剧本修改与瘦身检查

## R — 原文（Reading）

> “剧本是时间揉搓的艺术，不必事无巨细、面面俱到……瘦身是一件很重要的工作。”
>
> — 查理，《写好短剧》“短剧剧本修改的70个要点”

## I — 方法论骨架（Interpretation）

修改不是逐句润色，而是从四层逐级诊断：故事整体是否有清晰卖点、难度和持续悬念；人物是否兑现诉求、主动性、成长和关系变化；单场是否有冲突、状态变化、视觉动作和正负极；对白及其他细节是否口语、简洁、可拍。先找结构性病因，再删无功能材料，最后才补台词和道具。每次修改都要说明删改如何改变观众期待或制作可行性。

## A1 — 书中的应用（Past Application）

### 新手办公室喜剧改到修车行

- **问题**：作者发现编剧对办公室流程陌生，成片感不真实。
- **方法论的使用**：整体修改时换到作者熟悉的修车行环境，把主角职业、场景和人物优势统一。
- **结果**：通过“选择熟悉内容”提升真实感和可写性。

## A2 — 触发场景（Future Trigger）★

1. 用户有一稿剧本，感觉“头重脚轻、后半段乏力”。
2. 需要按清单检查人物设定、悬念、场次和对白。
3. 想知道哪些戏该删、合并或重写，而不是只改错别字。

### 语言信号

- “帮我做一轮剧本诊断和瘦身”
- “这稿子哪里有问题，按优先级怎么改”
- “检查我的人物/悬念/对白是否兑现”

### 与相邻 skill 的区分

- 与 `short-drama-ideation`：本 skill 假设已有故事稿，负责诊断，不从零提炼创意。
- 与 `short-drama-structure`：本 skill 用结构框架找病因，但不替代首次搭建。
- 与 `short-drama-scene`：本 skill 先排全稿优先级，后者专注单场重写。

## E — 可执行步骤（Execution）

1. **整体扫描**：标出卖点、主角任务难度、四幕转折、悬念连续性和结局，先处理结构性断裂。
2. **人物/场次扫描**：逐个核对主角、反派、配角的设定兑现、主动性、关系变化；逐场标记冲突、状态变化、信息差、正负极。
3. **瘦身与回归测试**：删除不确定、重复、无关动作、过量闪回/电话/独白和无功能伏笔，重读修改后的卡点与因果链。

## B — 边界（Boundary）★

- 没有梗概或场次材料时，只能提出诊断问题，不能假装完成修改。
- 实验电影、文学剧和非商业文本不应机械追求“爽”、倒计时或少对白。

### 失败模式与盲点

- 头重脚轻、悬念中断、角色设定不兑现、过多伏笔和闪回。
- 70 项清单来自作者商业影视偏好，不是经过统计验证的 universal rubric。
